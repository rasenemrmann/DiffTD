## Implementation Strategy

### MVP First (US1)

1. Phases 1–2, then Phase 3. Stop and validate: import a folder, compare two versions, without typing a folder name.
2. Then US2 (upload) and US4 (polish) — they make it comfortable; US3 completes the argument-free start.

### Risks

- Folder handles in IndexedDB differ between browser versions: degrade to "choose folder again" (T012).
- Large files: hashing and upload of 200 MB take time; progress per file in the `loading` state (T015, T026).
- Visual quality is subjective: T022 fixes a direction first, T030 verifies against the invariants in `contracts/ui-states.md` rather than taste.
